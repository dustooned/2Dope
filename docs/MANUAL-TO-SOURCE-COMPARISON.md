## Our design choices — proposals, not reference facts

1. Extend current rails and commands; preserve IDs, drawing assets, Line/Fill, undo/autosave and cross-workspace time. Decide how free spans map to existing exposure sequences before schema changes.
2. Present the action and affected scope before ripple/close-gap commits. Preserve the current comp-wide behavior unless the user approves a scope change; the earlier mockup's contiguous-rail rule is not authoritative.
3. Retain nested comps as a real animation tool. Treat organization-only groups as a separate decision; grouping/ungrouping must account for rendering, clocks and linked sound.
4. Offer shared media placement and scrub preferences through existing controls. Supported formats and preview lengths are our engineering choices, not implied by a familiar UI.

## Unknowns and limits

- Exact Dreams collision, gap, lock and nested-ripple edge cases remain unestablished by the saved sources; consult a specific official page only when an implementation decision requires it.
- Source shows group/ungroup operating on layer lists, whereas audio clips live on comps and link to layer IDs. Audio/link migration through those commands needs a focused verification; visual grouping comments do not prove audiovisual preservation.
- Nested rail timing needs comparison with rendered content for differing FPS, speed, loops and time remapping. This is a source-derived concern, not a reproduced runtime defect.
- Physical touch/Pencil behavior, current reference-app parity and available video-decoder formats remain unverified. Older study implementation badges are historical, not current defect findings.
